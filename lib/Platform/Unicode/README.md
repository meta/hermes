# Regenerating Unicode property tables

`UnicodeData.inc` is generated by `utils/genUnicodeTable.py --table properties`.
Edit the generator, not the generated file. The generator is pinned to Unicode
17.0.0 by `UnicodeDataFiles.VERSION`; its `URLS` map identifies the official
unicode.org inputs. It first reads input files from the current directory and
downloads missing files. Do not mix cached inputs from different versions.

Run these commands from the repository root with Python 3 and `clang-format`
available. Generate and format temporary files before replacing the checked-in
file, so a failed download or generator does not truncate it:

```sh
(
  set -e
  unicode_raw=$(mktemp)
  unicode_formatted=$(mktemp)
  trap 'rm -f "$unicode_raw" "$unicode_formatted"' EXIT
  python3 utils/genUnicodeTable.py --table properties > "$unicode_raw"
  clang-format --assume-filename=lib/Platform/Unicode/UnicodeData.inc \
    < "$unicode_raw" > "$unicode_formatted"
  cp "$unicode_formatted" lib/Platform/Unicode/UnicodeData.inc
  git diff --check
  git diff -- lib/Platform/Unicode/UnicodeData.inc
)
```

The generated header records the Unicode version and SHA1 of each of the 13
property-table inputs. When reproducing the same version, compare those hashes
with the checked-in header; its generation date may change. The generator also
emits `clang-format` markers around the provenance hashes. Table contents should
not change unless the inputs or generator changed. No manual brace repair or
other postprocessing is needed: the generator emits the outer `std::array`
aggregate braces as well as the individual range braces.

The property pool keeps readable inclusive endpoint pairs. C++ constant
evaluation packs them into 32-bit words, choosing the overflow table for long
ranges automatically. Do not calculate packed words or overflow indices by
hand. Static assertions validate the source ranges and compare every decoded
range with its original endpoints. If changing the encoding, update the
generator template and `decodeUnicodeRange` in `CharacterProperties.cpp`
together.

Build and run the focused tests with property escapes enabled:

```sh
cmake -S . -B build-unicode-asan -G Ninja -DCMAKE_BUILD_TYPE=Debug \
  -DHERMES_ENABLE_ADDRESS_SANITIZER=ON \
  -DHERMES_ENABLE_UNICODE_REGEXP_PROPERTY_ESCAPES=ON \
  -DCMAKE_CXX_FLAGS=-O1 -DCMAKE_C_FLAGS=-O1
cmake --build build-unicode-asan --parallel 4 \
  --target PlatformUnicodeTests HermesSupportTests
build-unicode-asan/unittests/PlatformUnicode/PlatformUnicodeTests
build-unicode-asan/unittests/Support/HermesSupportTests \
  --gtest_filter='Regex.*:RegExp.*'
```

For a Unicode version upgrade, update `UnicodeDataFiles.VERSION`, use inputs
from that version, and review the new hashes, ranges and aliases. The other
`--table` modes generate separate casing, normalization, collation and test-data
files; coordinate their regeneration when changing the shared Unicode version.
