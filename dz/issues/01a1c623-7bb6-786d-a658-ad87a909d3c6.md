Since IR type system v2 Phase 5, the program wrapper's `exports` argument
`{}` is a typed object literal of type `exactObject()`, so every typed
IRGen dump has a `UnionNarrowTrustedInst` on it. Harmless; it adds noise to
baselines. Consider not narrowing it, or typing it as `object`.
