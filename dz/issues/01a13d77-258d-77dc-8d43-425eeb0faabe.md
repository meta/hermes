The x86-64 polymorphic GetById chain (spec
doc/superpowers/specs/2026-10-14-jit-getbyid-polymorphic-design.md)
has no arm64 emitter yet: arm64 GetById still calls
_sh_ljs_get_by_id_rjs directly and records nothing. Port the helper
slot call, legacy-specialization recording and emitPolyChain to
lib/VM/JIT/arm64/JitEmitter-property.cpp; the shared records,
handler, progress term and demotion already work for arm64.

The shared-code changes of that feature (commits 01e305d36..c99aaead8:
JitFunctionData.h, JitCounters.h, JitCompiler.cpp, JitHandlers.{h,cpp},
CodeBlock.cpp) were never compiled for arm64: the host had no aarch64
cross toolchain or qemu. The first step of the port is an arm64 build
and the arm64 JIT suite (doc/JITTesting.md config 1) at that range, to
confirm the arm64 GetById path, where byIdSites stays empty, still
builds and behaves as before.
