7 arch-neutral jit/ lit tests fail on the arm64 tree (cmake-build-arm64,
qemu-aarch64-static) once it actually builds a complete hermes binary
(see the now-closed dz issue 01a06fe8 for why it previously could not
build at all):

    Hermes :: jit/construct.js
    Hermes :: jit/consts.js
    Hermes :: jit/envops.js
    Hermes :: jit/load-parent-notraps.js
    Hermes :: jit/misc.js
    Hermes :: jit/new-object.js
    Hermes :: jit/objops.js

All seven fail identically:

    error: CHECK-NEXT: expected string not found in input
    // CHECK-NEXT: JIT cold ById sites: {{[0-9]+}}

Root cause: commit a49199b35 ("JIT: x86-64: report ById sites left cold
by a compile") added Emitter::coldByIdSites_ to x86_64::Emitter only,
and in the SAME commit updated these seven arch-neutral test files
(they live under test/jit/, not test/jit/x86-64/, and are meant to run
on any JIT backend per test/jit/lit.local.cfg) to expect the resulting
"JIT cold ById sites: N" dump line under -Xjit=force
-Xdump-jitcode=2 --match-full-lines. JitCompiler.cpp only prints that
line when `em_.coldByIdSites_ > 0`; the field mirrored onto
arm64::Emitter to fix 01a06fe8 is permanently 0 there (the arm64
emitter does not yet track cold ById sites), so the line can never
appear on arm64 and these CHECK-NEXTs can never match.

No historical baseline exists where this passes: at a49199b35 and
every commit since, arm64 could not even compile (until 01a06fe8's
fix), so these tests have never actually run against an arm64 binary
with this feature present. Confirmed via `git log`/`git show
--stat a49199b35`: the same commit both added coldByIdSites_
(x86-64-only) and edited these seven test files.

Not fixed here: doing so is a design choice (gate these seven
UNSUPPORTED on non-x86-64 architectures the way the two
`*-inline-emitted-arm64.js` files gate the other way; make the
CHECK-NEXT conditional per architecture; or give arm64 its own
cold-site tracking, closing the dormancy the JIT recompilation task's
spec deliberately left open) that the JIT recompilation task's brief
did not authorize touching.

Reproduced 2026-09-05:
LIT_OPTS="-j8" LIT_FILTER="jit" cmake --build cmake-build-arm64 --target check-hermes
-> Expected Passes: 46, Unsupported Tests: 28, Unexpected Failures: 7 (the seven above).
