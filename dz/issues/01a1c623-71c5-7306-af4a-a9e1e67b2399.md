async function af(x: number): number { const y: number = x + 1; return y; }
    af(1);
    print("ok");

type mismatch in function \"af\"" after LowerGeneratorFunction: a value
typed `any` is stored into a frame slot typed `number`. Also fails on the
base master commit (3f124a87e23c), before the IR type system v2 stack.
