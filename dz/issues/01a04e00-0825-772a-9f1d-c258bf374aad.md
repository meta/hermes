The encode hoist (faa6c94b3) removed the #else arm that carried
static_assert(sizeof(SmallHermesValue) == sizeof(HermesValue), "the
inline store writes a 64-bit HermesValue"). Nothing replaces it. It is
currently unfalsifiable (SmallHermesValueAdaptor is 8 bytes whenever
HERMESVM_BOXED_DOUBLES is off), so this is a lost tripwire, not a hole;
re-add it next to the HV64 store so a future change to the adaptor
breaks the build instead of the emitted code.
